distributed rustc

Your other machines already have the cores.

crabfarm turns the computers you own into one build farm. Type crabfarm cargo build on the weak one, and the library crates compile on whichever machine has free capacity.

Install View the source

Early version. The first release distributes builds between Windows machines. Mixed-OS farms and proc macros on other systems are planned; see Platforms.

Three steps, no cargo configuration

Your projects stay untouched. crabfarm sets itself up as cargo's rustc wrapper only for the command you run through it.

  1. Create a farm

    On the machine with the most cores. It creates the farm's certificate authority and prints a one-time join code that is valid for ten minutes.

    $ crabfarm farm create
$ crabfarm node            # keep running
$ crabfarm farm invite
cf1-...@desktop:47070

  2. Join from your other machines

    Paste the code once. The machine gets its own certificate and starts its node.

    $ crabfarm farm join cf1-...@desktop:47070
$ crabfarm node            # keep running

  3. Build as usual, with crabfarm in front

    Any cargo command works. Library crates go to free machines; linking, build scripts and anything unusual stay on yours, so the result is the same as a local build.

    $ crabfarm cargo build --release
$ crabfarm status          # peers, free slots, local vs remote jobs

What runs where

The farm is about compiling. Anything that could behave differently on another machine does not leave yours.

Sent to the farm

  • Library crates, the bulk of a dependency tree
  • Whichever machine has free slots, balanced by load

Always built locally

  • Linking: binaries, tests, dynamic libraries
  • Build scripts and the cc crate
  • Incremental workspace crates

If anything goes wrong

A peer that vanished, a missing toolchain, a network error or a flag crabfarm does not know: that crate builds locally. Fallbacks are counted in crabfarm status, never hidden.

Security, in plain words

Only your own machines belong in a farm. Within it, nothing travels in the clear and nobody gets in without an invitation.

Closed membership

The first machine becomes the farm's certificate authority. Others join with a one-time code (ten minutes, single use) and receive a certificate that only this farm accepts.

Encrypted and authenticated

Every connection is TLS 1.3 with certificates checked in both directions. There is no plaintext, anonymous or "insecure" mode.

Encrypted at rest on other machines

Files a machine keeps for your later builds are encrypted with your machine's key, which never leaves it. Job folders are deleted when the job ends.

Trust each other fully

A farm member compiles your code and runs your proc macros, so it can run code of yours, and you can run code on it. Only join machines you own. crabfarm is not a sandbox against a hostile member.

Machines reach each other on a local network or over a VPN such as Tailscale or WireGuard. There is no relay and no cloud service, and crabfarm sends nothing to us.

Platforms

The binary builds for Windows, macOS and Linux on x86-64 and ARM. What a farm can distribute grows in three phases.

PhaseWhat worksStatus
1Windows to Windows farms: discovery, join, TLS, distributed library crates, fallback to localfirst release
2Jobs across operating systems (without proc macros), result cache, live status, opt-in autostartplanned
3Proc macros compiled for the machine that runs the jobplanned

Install

One binary, crabfarm. Put it on every machine of the farm.

From a GitHub release

# Windows, macOS and Linux: x86-64 and ARM
# 1. Download the archive for your platform:
#    github.com/rennerdo30/crabfarm/releases/latest
# 2. Check it against SHA256SUMS.txt
# 3. Unpack; put crabfarm on your PATH
$ crabfarm --version

Archives are .zip on Windows and .tar.gz elsewhere. They are not code-signed, so Windows or macOS may ask for confirmation on the first run.

With cargo

$ cargo install crabfarm
$ crabfarm --version

Builds on your machine, so there is no download prompt. Needs a current stable Rust toolchain.
