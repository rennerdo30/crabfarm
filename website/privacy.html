Privacy

This website

This site sets no cookies, runs no scripts, uses no analytics and loads nothing from other sites. It is served as static files by GitHub Pages. GitHub, the host, logs visitors' IP addresses and keeps its own server logs; see its privacy statement for how it handles them. We do not receive or evaluate those logs.

The crabfarm tool

crabfarm has no account and no telemetry, and it contacts no server of ours. It talks only to the other machines of your own farm, over mutually authenticated TLS 1.3. Those machines see the source files and build inputs of the jobs you send them while a job runs; that is why a farm should contain only machines you own.

Logs hold crate names, sizes, shortened hashes and timings, never file contents, environment values, keys, tokens or join codes.
